01 / OVERVIEW

Use color
to find a way forward.

ACTUAL GAMEPLAYDIRECTX / 2D

Switch among red, blue and yellow paint, shooting paintable blocks to progress. Each color changes movement—bouncing, sliding or wall traversal—combining action with puzzle decisions.

Use enemy color weaknesses, temporary solid slime platforms and ladders to reach the door on the right side of the level.

These implementation notes are based on the C++ source code and game documentation supplied for review.

01 — RED↥

Bounce

Landing on a red-painted platform applies upward velocity for a bounce.

02 — BLUE⇢

Slide

Blue platforms alter acceleration and damping to create slippery movement.

03 — YELLOW⊕

Wall movement

Yellow paint reduces wall-fall speed and enables wall jumps. Color is also used for enemy weaknesses.
