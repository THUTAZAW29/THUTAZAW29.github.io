06 / SECOND PROJECTDirectX 2D project

2D GAME PROJECT

CHROMA PAINTER

A C++/DirectX 2D platformer where different paint colors change how you navigate the level.

GAME OVERVIEW

Color changes the action.

A 2D action game where players fire different colored projectiles to change the properties of stage objects. Red, blue and yellow mechanics combine with a system for revealing invisible blocks.

C++DIRECTX 2DPLATFORMER

Controls: A/D (move), W/S (ladder), Space (jump), 1/2/3 (select red/blue/yellow), left click (shoot)

TECHNICAL BREAKDOWN ↗WATCH GAMEPLAY ↗
01 / PAINT SYSTEM

Paint changes platforms

Paint projectiles update paintable tile states on impact. Red gives bounce, blue changes sliding and yellow affects wall movement.

02 / LEVEL & COLLISION

50 × 28 tile level

A 32px tile map positions platforms, ladders and enemies. Rectangle collision checks and velocity updates control movement.

03 / GAME FLOW

From input to completion

I implemented animation, color switching, enemy interactions, fade effects and transitions among title, gameplay and result scenes.
