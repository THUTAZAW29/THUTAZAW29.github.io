# THUTA ZAW — Game Programmer Portfolio (4 Projects)

**Home Hearth → Chroma Painter → Space Shooter → １００年後 (Team Project) → About / Contact** の順に掲載した、日本語・英語対応のポートフォリオサイトです。

## 掲載プロジェクト

1. **Home Hearth** — C++ / DirectX、自作エンジンによる3Dマルチプレイヤー・アクションゲーム。TCP/UDP通信、3Dレンダリング、キャラクター制御などを紹介。HAL東京・HAL名古屋・HAL大阪の3校対抗コンテストでの技術力賞と、進級制作展（HAL EVENT WEEK）での独創力賞を記載。
2. **Chroma Painter** — C++ / DirectX 2D。色で足場の性質を変える2Dプラットフォームゲーム。ソースコードを確認した技術解説、スクリーンショット、YouTube動画を掲載。
3. **Space Shooter** — Unity 6 / C#、2Dシューティング。HP・エネルギー、ウェーブ管理、オブジェクトプールなどを、Unity Inspector画像とゲーム画面に基づいて紹介。
4. **１００年後 (100 Years Later)** — Unityを使用したグループゲーム企画。本人の担当は**プレイヤー移動の実装とマップ設計**。Miroの企画資料から、ストーリー、4つのステージ案、チーム全体で検討しているMemory Rewind / Memory Steal / Memory Policeのコンセプトを紹介。
